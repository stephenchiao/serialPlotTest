# 公共服务层

`navigation_safety.py` 已实现导航安全状态汇总，包括 STM32 断联、OPS9 失效、
前视相机冻结、完整车体边界、黄白禁入区域、道路观测超时和动态制动包络。
安全检查只返回报告，由 `robot_runtime` 执行暂停、恢复或终止停车。
行驶中的短暂视觉异常允许在最后有效帧后的 0.6 秒内继续；启动和暂停复核不使用
这个容错窗口。近障碍、OPS9 丢失仍立即暂停；通信中断保持暂停等待重连，确认
旧航点停止并完成感知复核后自动继续。地图越界及底层非通信硬故障仍终止停车。
复核超过 10 秒只提醒，持续等待有效数据。OPS9 丢失/航点超时需先查询确认旧航点
停止，再收到两帧新鲜、不同时间戳的有效定位后解锁；恢复仍要完成视觉复核。
非导航且未下发运动时不检查前摄像头，导航只检查前摄像头健康度。
参数与完整策略见 `docs/NAVIGATION_RUNTIME.md`。
